# Clapper — Actor Resume & Casting Call Telegram Bot (Persian/English)

> Telegram bot to build actor and film/theatre crew resumes, post casting calls and search talent. Persian-first, English second. Python, SQLite, consent-first personal data handling.

## Features

- Guided resume wizard (roles, skills, photos, work history)
- Casting-call posting and talent search with compact result cards
- Consent screen and "delete my data" command
- Admin panel: plans/quotas, ads, stats, export (CSV/ZIP)
- Importer for casting posts from channel exports
- Offline tests with mocked Telegram API

## Setup

```bash
python3 -m venv venv && ./venv/bin/pip install -r requirements.txt
export CAST_TELEGRAM_BOT_TOKEN=...    # from @BotFather
export OWNER_ID=123456789             # your numeric Telegram id (admin)
export OWNER_USERNAME=your_username SUPPORT_USERNAME=your_username
./run.sh
./venv/bin/python test_offline.py
```

> **Configuration note:** the owner/admin identity is read from environment variables (`OWNER_ID`, `OWNER_USERNAME`, `SUPPORT_USERNAME`) with the placeholder `example_owner`. Set them to your own values before running. Never commit bot tokens — they are read only from the environment.

مالک: @example_owner (شناسه‌ی عددی `100000001` از ابتدا ثبت شده؛ اگر پاک شود با اولین پیام همین یوزرنیم دوباره متصل می‌شود).

## تجربه‌ی کاربر (ساده برای هنرمندان)
* منوی اصلی فقط چند دکمه‌ی درشت: **📝 ساخت رزومه** (بعد از ثبت: 👤 رزومه من) · **🔍 جستجو** · **🎭 آگهی‌ها** · **📞 پشتیبانی** · ⚙️ بیشتر · 🌐 English. دستورهای میان‌بر هم هست (`/resume` `/search` `/calls` `/help` ...).
* **ویزارد رزومه**: هر بار یک سؤال کوتاه، با مثال یک‌خطی، نوار پیشرفت (مرحله ۳ از ۲۷)، دکمه‌ی «⏭ رد شدن» و «⬅️ برگشت» در هر مرحله. جنسیت، شهر (لیست سریع + «شهر دیگه»)، نقش‌ها، تجربه، رنگ مو/چشم/پوست، مهارت‌ها، نوع کار و ... همه با دکمه. ارقام فارسی/انگلیسی و سال شمسی/میلادی پذیرفته می‌شود.
* **ذخیره‌ی خودکار پیشرفت**: هر جواب همان لحظه در دیتابیس ذخیره می‌شود؛ کاربر هر وقت برگردد «▶️ ادامه» می‌بیند.
* فقط ۵ مورد ضروری است (نام، جنسیت، سال تولد، شهر، حداقل یک نقش)؛ بقیه اختیاری. بعد از ضروری‌ها همیشه «👁 دیدن رزومه» هست.
* **پیش‌نمایش** زیبا + یک دکمه‌ی «✅ تایید». بعد از تایید: ویرایش هر بخش، مخفی/نمایش، حذف رزومه.
* **رضایت‌نامه** قبل از شروع (ذخیره‌ی اطلاعات شخصی) و **«🗑 حذف اطلاعات من»** (رزومه، عکس‌ها روی دیسک، آگهی‌ها و درخواست‌ها را کامل پاک می‌کند).
* فیلدهای رزومه (جدا از هم): نام فارسی، نام هنری/لاتین، جنسیت، سال تولد، شهر، قد، وزن، رنگ مو، رنگ چشم، رنگ پوست (اختیاری)، مهارت‌ها (بازیگری/خوانندگی/رقص/ساز/زبان/رانندگی/ورزش/سایر — چندانتخابی + متن آزاد)، نقش‌ها (۱۳ مورد، چندانتخابی)، سطح تجربه، سابقه‌ی کار (چند مورد: عنوان، نوع، نقش، سال، کارگردان/شرکت؛ افزودن/ویرایش/حذف)، تحصیلات، جوایز/جشنواره، تلفن، تلگرام، ایمیل، اینستاگرام، لینک نمونه‌کار، دموریل، زمان آزاد و آمادگی سفر، دستمزد (اختیاری)، معرفی کوتاه، تا ۵ عکس.
* **عکس‌ها**: هم `file_id` تلگرام در دیتابیس ذخیره می‌شود و هم فایل روی دیسک در `media/` با نام ثابت `R000012_01.jpg` (شناسه‌ی رزومه + شماره). اگر دانلود شکست بخورد، `file_id` می‌ماند و بعداً (در شروع ربات و هنگام Export) دوباره تلاش می‌شود.

## جستجو (ادمین‌ها، تولید/کارگردان‌های تاییدشده، و دارندگان پلن با سهمیه‌ی دیدن)
فیلترهای ترکیبی با دکمه: متن آزاد، اسم، شهر، نقش، مهارت، زبان، جنسیت، تجربه، بازه‌ی سنی (از سال تولد)، بازه‌ی قد، فقط ویژه‌ها. نتایج صفحه‌بندی‌شده (کارت فشرده + «📄 رزومه کامل»). رزومه‌های مخفی/پیش‌نویس/مخفی‌شده‌ی ادمین برای غیرادمین دیده نمی‌شوند. جستجو نرمال‌سازی می‌کند (ی/ي، ک/ك، ارقام، نیم‌فاصله) و کاراکترهای LIKE را escape می‌کند.
ادمین روی هر نتیجه: **🚫 مخفی/👀 نمایش، ⭐ ویژه، 🗑 حذف** (با تایید). دیدن رزومه‌ی کامل برای غیرادمین از سهمیه‌ی ماهانه کم می‌شود (هر رزومه در ماه یک بار).

## تولید/کارگردان و آگهی‌ها
* «🎬 من کارگردان/تولید هستم» → ثبت‌نام با یک اسم؛ **تایید دستی ادمین اختیاری** است (پنل ادمین ← ⚙️ محدودیت‌ها ← ✅ تایید دستی ثبت‌نام تولید). پیش‌فرض: خاموش.
* آگهی جدید (۷ مرحله با دکمه): عنوان، نوع پروژه، نقش‌های موردنیاز، شهر، تاریخ (شمسی یا میلادی؛ به ISO تبدیل می‌شود)، توضیحات، راه ارتباط → پیش‌نمایش → انتشار. بستن/بازکردن/حذف، دیدن متقاضی‌ها (با رزومه‌ی کامل).
* هنرمند آگهی‌ها را ورق می‌زند و «📨 درخواست می‌دم» می‌زند (رزومه‌ی کامل لازم است)؛ صاحب آگهی خبر می‌گیرد.

## درآمدزایی (نمایشی؛ بدون پرداخت داخل ربات)
* **سهمیه‌ی رایگان ماهانه** (قابل ویرایش از پنل): دیدن رزومه‌ی کامل (پیش‌فرض ۵)، درخواست به آگهی (۵)، ثبت آگهی (۲). `-1` = نامحدود. ادمین‌ها نامحدودند. ماه به وقت تهران.
* **پلن‌ها**: عنوان، قیمت (متن آزاد)، مدت نمایشی، ویژگی‌ها، ⭐ محبوب، و سهمیه‌ی ماهانه‌ی هرکدام (دیدن/درخواست/آگهی؛ `-1` نامحدود) + تعداد روزِ اعتبار (`0` = بدون انقضا). **پرداخت بیرون از ربات و با پشتیبانی** انجام می‌شود؛ هیچ شماره کارت یا رسیدی در ربات نیست. ادمین از کارت کاربر «💎 اعطای پلن» یا «🎟 افزودن اعتبار» را می‌زند و کاربر خبر می‌گیرد. سقف کاربر = بیشترِ (سهمیه‌ی رایگان، سهمیه‌ی پلن)؛ پس از اتمام، اعتبار خرج می‌شود؛ بعد صفحه‌ی ارتقا با شناسه‌ی عددی و دکمه‌ی تماس با پشتیبان.
* **دعوت دوستان**: لینک اختصاصی `?start=ref_<id>`، پاداش قابل‌ویرایش برای دعوت‌کننده و دعوت‌شده (اعتبار)، دکمه‌ی اشتراک‌گذاری، جدول برترین‌ها. فقط برای کاربر جدیدی که هنوز رزومه ندارد.
* **تبلیغات/حامی**: تبلیغ متنی/عکس‌دار fa/en با دکمه‌ی لینک، شمارنده‌ی نمایش و (اختیاری) کلیک؛ دو جایگاه: 📰 «بین کارها» (هر N کار، فقط برای کاربران بدون پلن) و 📌 «حامی منوی اصلی» (یک خط زیر منو). ارسال تبلیغ همگانی (بدون دارندگان پلن و ادمین‌ها).
* **رزومه‌ی ویژه** و **آگهی ویژه**: ادمین با یک دکمه ⭐ می‌کند؛ در جستجو/لیست بالاتر می‌آید.

## 📤 Export برای وب‌سایت
دکمه‌ی «📤 خروجی (Export)» در پنل، یا `python3 export.py [--out DIR] [--db PATH] [--media DIR] [--no-drafts]` (آفلاین، بدون توکن):
`resumes.csv` (یک ردیف برای هر رزومه؛ فهرست‌ها با ` | `؛ UTF-8 با BOM برای اکسل) · `resumes.json` (ساختار تو در تو + enums با برچسب fa/en) · `photos.zip` (اگر از ۴۵ مگابایت بیشتر شود `photos-part1.zip`…) · `calls.json` · `SCHEMA.md`.
شناسه‌های پایدار (`R000012`, `W…`, `M…`, `C…`)، تاریخ‌ها ISO 8601 UTC، کدهای انگلیسی پایدار برای همه‌ی فیلدهای انتخابی. **مستند کامل ساختار و راهنمای ایمپورت به WordPress: [`SCHEMA.md`](SCHEMA.md).**
ذخیره‌سازی: SQLite با حالت WAL و جدول‌های نرمال‌شده `users, resumes, work_history, skills, roles, media` (+ calls, call_roles, applications, plans, ads, views, meta). خروجی‌ها حاوی اطلاعات شخصی‌اند؛ محرمانه نگه دارید.

* **مدیریت (اولویت اول):** هر آگهی با وضعیت `pending` ذخیره می‌شود و برای کاربران **نمایش داده نمی‌شود**. پنل ادمین ← **📥 آگهی‌های واردشده** (با شمارنده): 👀 مرور (کارت با منبع و هشدارها: ✅ تایید و انتشار · ✏️ ویرایش عنوان/شهر/تماس/متن · 🗑 حذف) · ✅ تایید گروهی (فقط بدون هشدار جدی) · 🤖 **انتشار خودکار (پیش‌فرض: خاموش)** · 🔄 همگام‌سازی. حتی با انتشار خودکار روشن، آگهی‌های دارای هشدار (`no_contact`, `roles_unclear`, `maybe_course`) در صف می‌مانند. مدیر اضافه می‌تواند تایید/ویرایش/حذف کند؛ فقط مالک انتشار خودکار را تغییر می‌دهد. مالک با هر همگام‌سازی که آگهی جدید بیاورد یک پیام کوتاه می‌گیرد.
* **نمایش به کاربر:** خط «📡 منبع: @farakhan_iziy1 — پست اصلی» با لینک پست، تاریخ انتشار در منبع، و به‌جای «📨 درخواست می‌دم» دکمه‌های **💬 تماس مستقیم** (تلگرام/واتساپ از همان پست) و «🔗 پست اصلی». اگر پست هیچ راه تماسی نداشته باشد، درخواست داخل بات (با رزومه) فعال می‌ماند. آگهی‌های واردشده در «آگهی‌های من» کاربران نمی‌آیند و با حذف اطلاعات مالک پاک نمی‌شوند.
* **دقت (صادقانه):** تحلیل با regex روی متن آزاد فارسی است، نه هوش مصنوعی. روی ۲۷۷ پست یک سال اخیر کانال: ~۱۷۸ پست آگهی تشخیص داده شد؛ تشخیص آگهی/غیرآگهی در بررسی دستی نمونه‌ها خوب بود ولی بی‌خطا نیست (مثلاً یک تبلیغ استودیو اشتباه آگهی شد و اصلاح شد). عنوان، نوع، نقش‌های اصلی، سن و تماس معمولاً درست‌اند؛ **شهر** در حدود نیمی از آگهی‌ها پیدا نمی‌شود (هشدار «شهر مشخص نیست»)، **نقش‌های عوامل** از روی کلمات حدس زده می‌شود و ممکن است کم/زیاد باشد، و مهلت «مهر ماه» به پایان همان ماه تبدیل می‌شود. به همین دلیل همه‌چیز اول در صف تایید است.
* **⚠️ حقوق محتوا:** متن‌ها و آگهی‌ها متعلق به صاحب کانال @farakhan_iziy1 (و آگهی‌دهندگان) است. ربات فقط با ذکر منبع و لینک پست نمایش می‌دهد و کپی تجاری/بدون ذکر منبع نمی‌کند، اما **مجوز صریح ندارد**. پیشنهاد: قبل از انتشار گسترده از صاحب کانال اجازه بگیرید (یا همکاری/تبلیغ توافق کنید)؛ در صورت درخواست ایشان، `CAST_IMPORT=0` و حذف آگهی‌های واردشده از پنل.

## ساختار فایل‌ها
`config.py` (نام/ثابت‌ها) · `bot.py` (polling، مسیر‌یابی، پروفایل بات) · `core.py` (API تلگرام، ردکشن توکن، i18n، دکمه‌ها، دانلود فایل) · `db.py` (SQLite/WAL/اسکیما/تراکنش) · `logic.py` (کاربر/ادمین/سهمیه/پلن/تبلیغ/دعوت/آمار) · `resumes.py` (CRUD، اعتبارسنجی، کارت، جستجو، عکس) · `wizard.py` (ویزارد) · `finder.py` (جستجو) · `importer.py` (ورود آگهی از کانال) · `castings.py` (آگهی‌ها) · `admin.py` · `ui.py` · `exporter.py` + `export.py` · `options.py` (گزینه‌ها با کد ثابت + برچسب fa/en) · `fa.py` (نرمال‌سازی فارسی، تبدیل شمسی) · `texts.py` (رشته‌ها؛ کلیدهای fa/en یکسان — تست می‌شود) · `assets/` (لوگو + `make_logo.py`) · `test_offline.py` · `run.sh`/`stop.sh`.

## امنیت و حریم خصوصی
توکن فقط از env خوانده می‌شود، در لاگ ردکشن می‌شود و هیچ‌جا چاپ نمی‌شود. `cast.db` با مجوز 600. کوئری‌ها پارامتری‌اند. CSV در برابر formula-injection خنثی می‌شود. پیام‌های همگانی HTML-escape می‌شوند. فقط چت خصوصی پردازش می‌شود.

## پروفایل بات، لوگو و دستورها
وضعیت زنده: بات با `run.sh` اجرا شده (`@clapper_me_bot`) و پروفایل زیر با Bot API ست و با `getMy*` بازخوانی و تایید شده است.
* **نام (≤۶۴):** `کلاکت | Clapper` — ثابت `BOT_NAME` در `config.py` (تغییر یک‌خطی؛ با شروع مجدد خودکار دوباره ست می‌شود. `setMyName` محدودیت نرخ دارد؛ اگر خطا داد بعداً تکرار می‌شود چون sha فقط با موفقیت کامل ذخیره می‌شود).
* **About / Short description (≤۱۲۰):**
  * fa (93 نویسه): `🎬 رزومه بازیگر و عوامل تئاتر و فیلم، کستینگ و فراخوان و آگهی بازیگر. بساز، پیدا کن، پیدا شو ✨`
  * en (97): `🎬 Actor & crew resumes, casting calls and auditions for theatre & film. Build, search, get cast ✨`
* **Description (≤۵۱۲؛ خط تبلیغات با پشتیبان اصلی جاری خودکار اضافه می‌شود):** متن کامل fa/en در `bot.py` → `DESC` و برای پیش‌فرض + fa + en ست می‌شود.
* **دستورها** (پیش‌فرض + fa + en، یکسان): `start` `resume` `search` `calls` `plans` `invite` `support` `help` `lang`
  * میان‌بُرهای تبلیغ‌نشده: `/menu` `/about` `/me` `/faq` · `/admin` (فقط مالک/مدیر) · `/cancel`.
* **لوگو:** `assets/logo.jpg` (۶۴۰×۶۴۰) و `assets/logo.png`؛ کلاکت + نور نورافکن با حال‌وهوای نئون. ساخت دوباره: `python3 assets/make_logo.py`. عکس بات با `setMyProfilePhoto` (Bot API 9.x) روی بات واقعی ست شد (`{"type":"static","photo":"attach://logo"}` + آپلود `logo.jpg`)؛ راه دستی جایگزین: BotFather ← `/setuserpic` ← `@clapper_me_bot` ← `logo.jpg`. نوشتن فارسی: `make_logo.py` از raqm استفاده می‌کند (اگر نبود arabic_reshaper+python-bidi با موتور BASIC)؛ هرگز دو بار شکل‌دهی نکنید وگرنه حروف جدا/برعکس می‌شود. لوگو در پیام خوشامد هم (با کش `file_id`) فرستاده می‌شود.
* ربات هنگام شروع همه‌ی این‌ها را خودش ست می‌کند (`setup_profile` در `bot.py`)؛ نیازی به وارد کردن دستی در BotFather نیست.

## آنچه با تست آفلاین پوشش داده شده و چه چیزی نه
تست‌ها (`test_offline.py`) با تلگرام شبیه‌سازی‌شده: ویزارد کامل، اعتبارسنجی، همه‌ی فیلترهای جستجو و ترکیب‌شان، دسترسی‌ها (کاربر/مدیر اضافه/مالک)، آگهی و درخواست و سهمیه‌ها، پلن/اعتبار/دعوت/تبلیغ، Export (CSV/JSON/ZIP/CLI)، حذف اطلاعات، ردکشن توکن، دو زبانه بودن همه‌ی صفحه‌ها. **آزمایش کاربر واقعی انجام نشده**؛ فقط اتصال (`getMe`)، polling و ست شدن پروفایل روی تلگرام واقعی تایید شده. رفتار واقعی API، دانلود واقعی عکس، محدودیت نرخ ارسال همگانی و ظاهر دکمه‌ها روی گوشی باید بعد از راه‌اندازی بررسی شود.
